# 股息率买入清单（公开版）

这是一个不含个人资产、持仓数量、交易成本、账户权重和资金规模的静态研究页面。

## 数据边界

- `config/strategy.json`：人工维护的正常化股息、买入价格地图和风险判断。
- `data/quotes.json`：自动更新的最新收盘价、交易日期和数据源状态。
- `dist/assets/stocks.js`：由构建脚本生成，页面只读取这个公开数据文件。

自动化只更新市场价格，不会修改正常化股息或投资策略。

## 本地更新

需要 Python 3.11 或更高版本，不依赖第三方包：

### 图形化维护股票池

Windows用户可以直接双击：

```text
启动股票池管理器.cmd
```

管理器只监听本机 `127.0.0.1:4186`，提供新增、编辑、复制和删除功能。保存时会：

1. 自动备份原策略和行情；
2. 根据正常化股息和目标股息率计算三档价格；
3. 为新增股票获取最新行情；
4. 校验公开数据；
5. 重新生成看板；
6. 失败时恢复保存前的配置。

备份位于本地 `config/backups/`，不会提交到公开仓库。

### 命令行更新行情

```powershell
./scripts/update_local.ps1
```

也可以分步运行：

```powershell
python scripts/fetch_quotes.py
python scripts/validate_data.py
python scripts/build_site.py
```

抓取脚本包含基础保护：无效价格拒绝写入、单次变化超过20%时保留旧值、抓取失败时保留上一期数据。

## GitHub Pages

仓库根目录的 `index.html` 会自动进入 `dist/` 中的看板。将GitHub Pages发布源设置为默认分支的根目录即可。

`.github/workflows/update.yml`按以下时间更新：

- 北京时间交易日16:35：A股和港股；
- 北京时间交易日次日06:35：美股最近完成的收盘价。

GitHub定时任务可能延迟，页面始终显示数据源返回的实际交易日期。

页面中的正常化或 Forward 股息包含估算值，仅用于展示分析框架，不构成证券推荐或收益承诺。
